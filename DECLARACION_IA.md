# Declaración de uso de inteligencia artificial

Para la elaboración de este trabajo se utilizó una herramienta de inteligencia artificial como apoyo para interpretar la consigna, organizar la estructura del proyecto, redactar documentación y proponer código inicial para las operaciones CRUD.

Las decisiones sobre el modelo se basaron en la base de datos de Esports trabajada en la materia. El proyecto debe revisarse y ejecutarse en el entorno local antes de su evaluación; la configuración real de la base y las evidencias de funcionamiento corresponden al estudiante.
